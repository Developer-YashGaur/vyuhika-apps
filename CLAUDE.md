# Project: Vyuhika Apps
A marketplace of useful AI web apps (some free, some paid), hosted at apps.vyuhika.com.
Owner is a beginner-to-intermediate dev (basic Python, SQL). Keep code simple and readable.

## Rules
- Stack: Next.js (App Router), Tailwind CSS, Framer Motion. Deploy on Vercel.
- Explain each change in 2-3 simple sentences after making it.
- Work in small steps. Never build more than one feature at a time.
- Secrets only in .env.local. Never hardcode API keys. Keep .env* in .gitignore.
- Write tests for logic and run them before saying a task is done.
- Mobile-first, responsive, accessible (good contrast, keyboard friendly).

## Design: futuristic AI world
- Dark deep-space background (#050816), neon cyan (#22d3ee) and violet (#8b5cf6) accents.
- Glassmorphism cards, soft glows, smooth Framer Motion animations.
- Animated particle / neural-network background.
- Brand: "Vyuhika" glowing wordmark. Tagline: "Intelligence, built in public."
- Respect prefers-reduced-motion
